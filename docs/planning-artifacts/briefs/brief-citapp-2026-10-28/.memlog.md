- (decision) Producto: app de reservas/agenda para profesionales independientes que trabajan por citas (genérico, no solo barberos); elegido sobre DAW musical, dev tools y otras ideas
- (decision) Meta: generar ingresos reales (suscripción), lanzamiento propio de Daniel
- (decision) Cliente final reserva por link web sin instalar app; el profesional usa app mobile
- (decision) Stack: Expo/React Native + TypeScript, UI con Tamagui, backend Supabase (free tier), validación Zod, contratos de API con Postman
- (decision) Prioridad: seguridad fuerte (RLS, validación en endpoints) y diseño elegante que no parezca hecho por IA
- (assumption) Mercado inicial Colombia/LatAm, cuña frente a Booksy/Fresha/AgendaPro: simple, en español, barato, recordatorios por WhatsApp
- (assumption) Monetización freemium: plan gratis limitado y plan pago de 5 a 10 USD/mes
- (change) UI: se reemplaza Tamagui por NativeWind + React Native Reusables (componentes propios en el repo, comunidad grande, mejor con agentes de IA); versiones a verificar en fase de arquitectura
- (decision) Diseño: identidad visual única y propia, no el look por defecto de shadcn/reusables; se define sistema de diseño propio en fase UX
